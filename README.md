# FATE EXECUTOR / 命运执行者

Poker hands decide your fate in this roguelike card game.

## Play

### [▶ Play in Browser](https://terry3095320679.github.io/FATE-EXECUTOR/)

### [⬇ Download for Windows](https://github.com/terry3095320679/FATE-EXECUTOR/releases/latest/download/FATE_EXECUTOR_Windows_x64.exe)

No installation or game engine is required. The browser version runs directly on the page. The Windows download is a single `.exe` file.

## How to Play

1. Draw up to eight cards.
2. Select one to five cards to form the best poker hand.
3. Confirm to attack, or refresh selected cards without ending the turn.
4. Build your deck, collect trinkets, and choose your next destination.
5. Survive increasingly dangerous battles.

Ace is always high (`A = 14`). The game supports English and Simplified Chinese.
